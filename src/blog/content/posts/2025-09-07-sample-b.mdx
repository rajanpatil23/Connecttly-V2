  <p style={{ margin: 0, color: '#475569' }}>Turn names and companies into verified emails at scale.</p>

### The Process:

**Step 1:** Prepare your CSV with:
- First name
- Last name
- Company domain (or company name)

**Step 2:** Upload to a bulk finder (Evaboot, Hunter Bulk, Apollo, Cognism, Lusha)

**Step 3:** Let it run (usually 5-30 minutes)

**Step 4:** Download enriched CSV with verification status

### Verification Status Explained:

| Status | Meaning | Action |
|--------|---------|--------|
| ✅ **Valid** | Email exists and accepts mail | Safe to send |
| ⚠️ **Risky** | Might be catch-all or role-based | Use with caution |
| ❌ **Invalid** | Doesn't exist or bounces | Don't send |
| 🔍 **Unknown** | Couldn't verify | Verify again or skip |

## ❓ FAQ

<div style={{

  padding: '24px',
  marginTop: '32px'
}}>

### What's the fastest way to get a few emails?

Check **Contact info / About** sections first, then use a Chrome extension on the profile. Always **verify** before sending.

### How do I scale to thousands of emails?

Use **Sales Navigator** to build targeted searches → **export** with Evaboot → **bulk enrich & verify** → import to CRM and run personalized sequences.

### Is scraping emails from LinkedIn legal?

Pulling emails without consent may violate LinkedIn's TOS and local privacy laws. Prefer opt-in, publicly listed, or verified **work** emails with legitimate interest, and always provide opt-out options.

### What if I can't find a work email?

Try these in order:
1. Guess the pattern using company domain
2. Verify with Hunter or similar tool
3. Ask directly on LinkedIn
4. Try company contact page
5. Reach out via mutual connection

### Which tools are best for beginners?

Start with **free tiers**:
- **Hunter** (25 credits/month) - Great for domain search
- **Apollo** (50 credits/month) - Good all-rounder
- **LinkedIn export** (free) - Use your existing network

### How do I avoid getting my LinkedIn account restricted?

- Use approved tools only
- Don't automate connection requests
- Respect daily limits (50-100 actions/day)
- Space out activities naturally
- Don't mass message without personalization
